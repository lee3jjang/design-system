# Oat 디자인 시스템

실제 물건을 조작하는 느낌의 웹앱 디자인 시스템입니다. shadcn/ui(Tailwind v4) 위에 얹어 쓰도록 만들었습니다.

- 키는 위에서 Z축으로 눌리고, 켜지거나 선택된 상태는 반쯤 눌린 채 걸려 있습니다.
- 물건은 오른쪽 아래에서 보는 각도로 그립니다(옆면이 오른쪽·아래에 보임).
- 어른도 읽기 편하게: 본문 17px, 누르는 곳 50px 안팎, 글자 대비 4.5:1 이상.
- 색: 이끼 아이보리 `#f3f1e7`, 먹초록 `#17221a`, 숲 초록 `#2f5a3c`, 반딧불 `#e8b45a`. 글꼴은 Noto Sans KR.

## 보기

`index.html`을 브라우저로 열면 됩니다. 문서와 동작하는 견본이 한 파일에 들어 있습니다.

- 기본: 색, 글자 단계, 원칙
- 누르기: 키 버튼, 더보기 버튼
- 켜고 끄기: 누름 스위치, 미끄럼 스위치, 체크박스
- 고르기: 프리셋 버튼(라디오·탭), 사이드 메뉴, 다이얼, 넘김판, 드롭다운, 페이더와 계량기
- 입력: 텍스트·검색·이메일·전화번호·비밀번호·숫자·금액·날짜·시간·일시
- 보여 주기: 뱃지, 카드, LED 진행 막대, 서랍 아코디언, 표와 쪽 넘기기
- 띄우기: 확인 창, 옆 판, 영수증 알림, 떠 있는 창
- 코드: `app/globals.css`에 붙여 넣을 토큰

운영체제의 '움직임 줄이기'가 켜져 있으면 애니메이션이 꺼집니다. 페이지 위쪽의 '움직임' 스위치로 켤 수 있습니다.

# Riso 디자인 시스템

Oat와 정반대로 가는 두 번째 시스템입니다. 리소그래프 2도 인쇄물처럼, 평평한 종이 위에 잉크 두 가지와 괘선만 씁니다. `riso/index.html`을 열면 됩니다(Pages: `/design-system/riso/`).

- 그림자·입체·둥근 모서리 없음. 깊이는 판의 어긋남으로만 표현합니다.
- 두 번째 판(핑크)은 평소 3px·2px 어긋나 있고, 마우스를 올리면 더 벌어지고, 누르면 딱 맞춰집니다.
- 초점은 크롭 마크, 비활성·빈 자리는 망점, 선택은 먹 반전.
- 색: 종이 `#f2ede2`, 먹 `#1b1a17`, 블루 `#2c4fa0`, 핑크 `#ff4fa7`. 글꼴은 Noto Serif KR(제목), IBM Plex Sans KR(본문), IBM Plex Mono(숫자·라벨).
- Oat와 같은 범위의 견본: 버튼·더보기 메뉴, 스위치·체크박스·라디오, 분할 버튼·탭·칩·드롭다운·눈금자·사이드 메뉴, 각종 입력, 뱃지·도장·카드·진행·접기·표·빈 상태, 확인 창·옆 판·알림, 그리고 `globals.css` 토큰.

# Arcology 디자인 시스템

세 번째 시스템. 하늘이 닫힌 뒤 지하 구조체를 관리하는 단말이라는 디스토피아 세계관에, 건축 도면 문법과 게임 HUD를 섞었습니다. `arcology/index.html`(Pages: `/design-system/arcology/`).

- 섹션은 지하로 내려가는 층(L00 → B07). 상단 내비게이션은 승강기 층 표시, 페이지 뒤에는 구조 그리드 축(A–D).
- 호버하면 주황 작도선이, 키보드 초점이 오면 청색 작도선이 모서리를 지나 뻗습니다. 누르면 단면이 잘려 해칭이 드러납니다.
- 평면도 기호를 컨트롤로: 문이 열리는 격벽 스위치, 개구부(X) 체크박스, 축 기호 라디오, 표제란 입력, 개정 삼각형(△) 오류, 세대 평면 카드, 일람표.
- 게임 요소: 20칸 자원 계기, 길게 눌러 실행(1.2초), 통금 카운트다운 HUD, 구내 방송 알림.
- 색: Night `#0d0e0f`, Bone `#e6e1d3`, Sodium `#ff8a1f`, Cyan `#74c6d8`, Alarm `#ff4b3e`. 글꼴은 Black Han Sans, Gothic A1, Chakra Petch, JetBrains Mono.

# Dal(달) 디자인 시스템

네 번째 시스템. 조선 백자와 한옥을 모티브로, 게임 UI의 손맛을 웹에 옮겼습니다. `dal/index.html`(Pages: `/design-system/dal/`).

- 버튼마다 다른 물건: 청화 두 줄 테를 두른 유약 버튼(누르면 굽 위로 내려앉음), 기와지붕을 얹은 현판 버튼, 놋쇠 문고리 아이콘 버튼, 낙관이 찍히는 도장 버튼.
- 한옥 컨트롤: 창호지 미닫이 스위치, 나무 홈 속 백자 구슬 토글, 붓 체크, 엽전 라디오, 호패 필터, 서책 탭, 반닫이 장석 판, 족자 옆 판.
- 게임 요소: 레벨·경험치·재화 HUD, 등급별 아이템 카드(백자 → 청화 → 진사 → 달항아리 전설), 가마 굽기 진행, 퀘스트 단계, 아이템 획득 알림.
- 색: 한지 `#f3eee2`, 백자 `#fcfbf6`, 청화 `#24418f`, 진사 `#a5302a`, 소나무 `#6e4527`, 놋쇠 `#c79a3c`. 글꼴은 Song Myung, Gowun Batang, Gowun Dodum.

# Canopy 디자인 시스템

다섯 번째 시스템. 열대우림 한가운데 세운 공방에서 나무, 대나무, 덩굴, 잎, 씨앗, 강돌로 손수 만든 도구들. `canopy/index.html`(Pages: `/design-system/canopy/`).

- 그리는 방법 하나로 통일: 진한 고동색 외곽선 3px, 평평한 면, 위쪽 밝은 띠, 아래 굽.
- 버튼: 잎사귀(주요 동작), 등나무로 묶은 판자, 대나무 통, 붉은 흙(위험), 강돌, 통나무 단면 아이콘 버튼, 두드리는 북(가장 큰 행동).
- 컨트롤: 횃불 스위치, 대나무 홈 구슬 토글, 엮은 상자 체크, 새싹이 돋는 씨앗 라디오, 흔들다리 분할 버튼, 나뭇가지에 매단 탭, 강돌 필터, 대나무 물길 슬라이더, 이정표 사이드 메뉴.
- 게임 요소: 재료 HUD(나무·덩굴·돌·물), 제작 카드(재료 → 결과, 등급), 조롱박 물통, 징검다리 단계, 잎 쪽지 알림(얻은 재료가 HUD에 더해짐).
- 색: 캐노피 `#12352a`, 잎 `#3f8f4f`, 나무 `#a8693a`, 대나무 `#cdb75c`, 나무껍질 종이 `#f4e8cc`, 꽃 `#f0a422`, 붉은 흙 `#c8532d`. 글꼴은 Jua, Nanum Gothic.

# Sansa(산사) 디자인 시스템

여섯 번째 시스템. 새벽 산사처럼 차분하고 자연스러운 화면. `sansa/index.html`(Pages: `/design-system/sansa/`).

- 판 하나가 법당 한 칸: 석간주 기둥 둘과 주춧돌, 위에는 모로단청 창방(양 끝 머리초, 가운데는 선), 처마 끝에는 흔들리는 풍경.
- 색은 절에 있는 만큼: 한지, 바랜 나무, 단청 바탕색 뇌록(주요 동작), 석간주(강조·취소), 군청·황토·연꽃 분홍은 조금.
- 컨트롤: 양 끝만 단청을 입힌 버튼, 범종(가장 큰 행동, 소리 결이 번짐), 목탁(확인 "똑"), 염주알 아이콘 버튼, 연등 스위치, 풍경 소리 스위치, 나무 빗장 토글, 먹 붓 체크, 봉오리가 벌어지는 연꽃 라디오, 징검돌 분할 버튼, 꽃살문 탭(고르면 문이 열림), 연등 필터, 향 슬라이더(불씨가 손잡이), 일주문→요사채 절길 메뉴.
- 보여 주기: 소원 꼬리표 뱃지, 기와지붕 전각 카드, 108배 염주 카운터, 촛불 진행, 문을 지나는 단계, 접은 경전 아코디언, 템플스테이 일과표.
- 움직임은 종을 친 듯 살짝 울리고 천천히 가라앉음. 글꼴은 Hahmlet, Noto Sans KR.

# Abyss 디자인 시스템

수심 3,042m 심해 연구 기지. 검은 외곽선, 황동 테, 두꺼운 유리라는 한 가지 그리는 방식. 청록 생물광은 주요 동작과 켜진 것에만. 현창 히어로, 소나 핑 CTA, 밸브 휠·에어록 스위치, 압력 해치 체크, 해파리 라디오, 잠수함 손잡이 수심 슬라이더, 갑판 단면 메뉴, 압력 다이얼·산소 탱크, 생물 표본 카드, 소나 접촉 알림. `abyss/index.html`

# Atomic 디자인 시스템

1962년 길가의 우주시대 다이너. 잉크 외곽선, 크롬 테, 파스텔 에나멜(청록·산호·겨자). 주크박스 열쇠 버튼, 카운트다운 로켓 발사 CTA, 계기판 로커·TV 채널 손잡이 스위치, 펀치 카드 체크, 주크박스 램프 라디오, FM 튜너 슬라이더, 다이너 메뉴판 사이드 메뉴, 행성 엽서 카드, 연료 게이지, TV 확인 창, 로켓 해치 옆 판, 전보 테이프 알림. `atomic/index.html`

# Riad 디자인 시스템

페스 메디나 안 리아드의 중정. 모든 판은 젤리주 타일 띠 테, 모서리 놋쇠 별 메달, 위쪽 회반죽(겝스) 아케이드. 유약 타일 버튼, 문고리를 두드리면 열리는 리아드 문 CTA, 민트 차 따르기 확인, 별빛을 뿌리는 놋쇠 등불·분수 스위치, 뒤집히는 타일 체크, 여덟 꼭지 별 라디오, 말굽 아치 탭, 분수 둘레 여덟 방 메뉴, 러그 카드, 찻잔 게이지·모자이크 진행, 열쇠 구멍 아치 확인 창, 밀랍 봉인 엽서 알림. `riad/index.html`

# Zoo Orbit 디자인 시스템

고양이 선장·강아지 조종사·토끼 기관사·펭귄 항법사·햄스터 발전 담당이 모는 우주선 계기판. 은백색 선체 패널, 남색 외곽선, 리벳, 안전 주황·박하·덮개 아래 빨강, 인광 초록 CRT. 발바닥 탑승 버튼, 덮개를 열어야 누르는 위험 버튼, 3-2-1 발사 CTA, 항공 토글 뱅크·쳇바퀴 발전기 스위치, 체크리스트 클립보드, 행성 라디오, CRT 채널 탭, 스로틀 레버 슬라이더, 로켓 단면 갑판 메뉴, 승무원 ID 카드, 산소 탱크·중력 다이얼·간식 게이지, 에어록 경고 창, 지구 관제센터 교신 알림. `zoo/index.html`
