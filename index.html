이 컴퓨터는 "애니메이션 줄이기"가 켜져 있어서 움직임을 꺼 두었어요. 위쪽 움직임 스위치를 켜면 누르고 돌리는 움직임을 볼 수 있어요.

기본

모든 컨트롤은 윗면과 옆면이 있는 물건입니다. 옆면 두께는 6px(--depth)이고, 누르면 윗면이 그만큼 내려갑니다. 판(패널)은 살짝 파여 있고, 입력 칸은 더 깊이 파인 홈입니다.

  1. 위에서 누른다. 버튼은 옆으로 기울지 않고 Z축으로 눌립니다. 누르는 데 0.05초, 놓으면 0.34초 동안 살짝 넘쳤다 제자리.
  2. 걸리는 것은 걸린 채로. 켜진 스위치, 선택된 버튼은 반쯤 눌린 채 남아 있어 상태가 높이로 보입니다.
  3. 불이 들어온다. 켜짐은 호박색 램프로, 선택은 윗면의 초록 표시로 알립니다. 글자도 함께 씁니다.
  4. 읽기 쉽게. 본문 17px, 누르는 곳 50px 안팎, 글자 대비 4.5:1 이상. 움직임 줄이기 설정이면 움직임을 끕니다.

띄우기

화면 위에 무언가를 올려놓는 방식도 물건처럼.

확인 창 · 옆 판 · 영수증

확인 창은 위에서 책상에 떨어지듯 툭 놓이고, 옆 판은 밀려 들어오며 살짝 넘칩니다. 알림은 영수증처럼 아래 틈에서 인쇄되어 나오고, 시간이 지나면 찢겨 나갑니다.

  • Esc나 바깥을 눌러 닫습니다.

떠 있는 창 게임 인벤토리처럼

열어 둔 채 다른 일을 할 수 있는 창. 제목판을 잡고 끌면 창이 살짝 들려 따라오고, 놓으면 그 자리에 내려앉습니다. 모서리 쇠붙이와 이중 테두리로 '틀'을 분명하게 만듭니다.

  • 뒤 화면을 가리지 않아요(어둡게 하지 않음).
  • 누른 창이 맨 앞으로 옵니다.
  • Esc나 ✕로 닫고, 칸은 방향키로 옮깁니다.

.key {
  --travel: 0px;
  border: 1.5px solid var(--foreground);
  border-radius: var(--radius);
  background: var(--cap);
  transform: translate(calc(var(--travel) * .6), var(--travel));
  box-shadow:
    calc((var(--depth) - var(--travel)) * .6) calc(var(--depth) - var(--travel)) 0 -1.5px var(--cap-wall),
    calc((var(--depth) - var(--travel)) * .6) calc(var(--depth) - var(--travel)) 0 0 var(--foreground);
  transition: transform var(--dur-spring) var(--ease-press),
              box-shadow var(--dur-spring) var(--ease-press);
}
.key:active { --travel: calc(var(--depth) - 1px); transition-duration: var(--dur-press); }
.key[aria-pressed="true"] { --travel: calc(var(--depth) - 2.5px); } /* 걸린 상태 */
