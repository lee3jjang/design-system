Atomic!

내일은 달에서 아침을 먹을 거예요.

1962년, 길가의 우주시대 다이너. 버튼은 주크박스 열쇠, 스위치는 계기판 로커, 고르는 것은 라디오 다이얼. 모든 것에 크롬 테두리와 파스텔 에나멜을 입혔습니다.

Righteous도현체해바라기체
01

기초

그리는 방법은 하나. 잉크 외곽선, 크롬 테두리, 파스텔 에나멜 면, 반짝이는 하이라이트 하나, 그리고 아래로 짧은 굽. 모든 물건이 같은 공장에서 나온 것처럼 보이게 합니다.

글자

제목은 둥글고 굵은 Righteous와 도현체. 다이너 간판처럼 읽힙니다. 본문은 해바라기체 17px.

  • 영문은 Righteous, 한글은 도현체가 자동으로 맡습니다.
  • 숫자는 Righteous로 계기판처럼.
  1. 한 공장에서 찍어 낸다외곽선 2.5px 잉크, 크롬 테두리, 에나멜 면. 굵기와 재료가 같으면 모든 물건이 한 세트가 됩니다.
  2. 색이 곧 역할청록은 주요 동작, 겨자는 가장 큰 행동과 불빛, 산호는 장식과 강조, 로켓 빨강은 되돌릴 수 없는 일.
  3. 누르면 들어간다모든 버튼 아래에는 굽이 있어 누르면 그만큼 들어가고, 놓으면 용수철처럼 돌아옵니다.
  4. 낙관적으로, 그러나 읽히게본문 17px, 누르는 곳 44px 이상, 글자 대비 4.5:1 이상. 움직임 줄이기 설정이면 반짝임과 발사를 멈춥니다.
02

누르기

주크박스 열쇠, 다이너 메뉴판 버튼, 꼬리 날개, 그리고 빨간 중단 버튼. 크롬 테두리가 있으면 기계, 없으면 다이너.

버튼 종류

청록 주크박스 열쇠가 기본 주요 동작. 불빛 램프가 켜져 있어 손이 먼저 갑니다. 다이너는 보조, 꼬리 날개는 강조, 빨강은 되돌릴 수 없는 일.

  • 레이블은 짧은 동사: "예약하기".
  • 새 소식은 별 스티커 숫자로.
3

크기와 상태

쓸 수 없을 때는 색이 빠진 회색 에나멜. 이유를 레이블에 함께 적어 주세요. 일하는 중에는 작은 원자가 궤도를 돕니다.

계기판 손잡이

아이콘만 있는 버튼은 계기판의 둥근 손잡이. 톱니 무늬 크롬 테두리가 있고, 올리면 살짝 돌아갑니다.

  • 이름(aria-label)과 말풍선을 꼭 붙입니다.
좋아요 주크박스 틀기 엽서로 보내기

발사 버튼

한 화면에 하나뿐인 가장 큰 행동. 누르면 계기판이 3, 2, 1을 세고 로켓이 떠오릅니다. 세는 동안에는 다시 눌리지 않습니다.

  • 숫자는 화면 읽기 프로그램에도 읽어 줍니다.

더보기 메뉴

자주 쓰지 않는 동작은 접어 둡니다. ↑↓로 움직이고, Esc로 닫습니다.

03

켜고 끄기

켜는 것은 계기판 로커와 TV 채널 손잡이, 여럿 고르는 것은 천공 카드, 하나 고르는 것은 주크박스 램프.

로커 스위치

큰 설정. 누른 쪽이 들어가고, 켜지면 청록빛이 돌며 위의 파일럿 램프에 불이 들어옵니다. 켜짐/꺼짐을 글자로도 적습니다.

TV 채널 손잡이

돌려서 켜는 스위치. 빨간 눈금이 "끔"에서 "켬"으로 돌아갑니다. 공간이 넉넉한 설정 화면에 씁니다.

천공 카드 체크

여러 개를 고를 때. 고르면 카드에 구멍이 뚫리고 체크가 찍힙니다. 일부만 고르면 "전부"에는 반쯤 뚫린 홈이 생깁니다.

우주여행 짐 꾸리기

주크박스 램프 라디오

하나만 고를 때. 고른 곡의 선택 램프에만 겨자색 불이 들어옵니다.

07

띄우기

확인 창은 다리가 벌어진 TV, 옆 판은 리벳이 박힌 로켓 해치, 알림은 전보 테이프.

TV 확인 창

되돌릴 수 없는 일 앞에서. TV가 켜지듯 나타나고, 버튼은 결과를 말합니다. Esc나 바깥을 누르면 닫힙니다.

로켓 해치 옆 판

지금 화면을 떠나지 않고 자세히 볼 때. 오른쪽에서 해치가 열립니다. 초점은 판 안에 머물고, Esc나 어두운 바깥을 누르면 닫힙니다.

전보 알림

무언가 끝났을 때 오른쪽 위로 전보 테이프가 감겨 나옵니다. 5초 뒤 사라지고, 오류는 role="alert"로 바로 읽어 줍니다.
