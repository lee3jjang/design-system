01

기초

Riso는 공판 인쇄기(리소그래프)로 찍은 인쇄물에서 왔습니다. 평평한 종이, 단색 잉크, 그리고 판이 조금씩 어긋나는 데서 생기는 손맛. 화면 안의 모든 것은 이 세 가지로만 그립니다.

겹쳐 찍기. 두 잉크는 곱하기(multiply)로 겹칩니다. 겹친 곳은 짙은 보라가 됩니다. 세 번째 색을 따로 만들지 않습니다.

어긋남 = 대기. 평소에는 핑크 판이 3px·2px 어긋나 있습니다. 마우스를 올리면 더 벌어지고, 누르면 0으로 맞춰집니다.

망점 = 덜 찍힌 것. 비활성, 빈 자리, 진행 중처럼 '아직'인 상태는 꽉 찬 잉크 대신 망점으로 칠합니다.

  1. 평평하게.그림자, 그라데이션, 둥근 모서리를 쓰지 않습니다. 겹친 판의 어긋남이 깊이를 대신합니다. (원형 컨트롤과 칩만 예외)
  2. 괘선이 곧 구조.카드와 판은 2px 먹 괘선으로 나눕니다. 덜 중요한 구분은 1px 회색 괘선이나 점선.
  3. 잉크는 두 가지만.블루는 동작과 선택, 핑크는 강조와 어긋남. 상태 색(초록·빨강·노랑)은 글자와 함께만.
  4. 읽히게.본문 16.5px, 누르는 곳 44px 이상, 글자 대비 4.5:1 이상. 핑크는 글자색으로 쓰지 않습니다(진한 --pink-ink만).
02

누르기

버튼은 잉크가 꽉 찬 사각형 위에 핑크 테두리 판이 하나 더 찍혀 있는 구조입니다. 누르면 판이 맞춰지고, 잉크가 한 번 더 진해집니다.

버튼

한 화면에 블루 버튼은 하나. 나머지는 테두리만 있는 버튼이나 밑줄 버튼으로.

  • 레이블은 동사로 끝냅니다: "저장하기".
  • 위험한 동작은 빨강 + 먹 판.

크기와 상태

작은 버튼은 표나 툴바 안에서만. 비활성은 망점으로 덜 찍힌 판처럼, 불러오는 중에는 글자를 바꿔 알립니다.

  • 아이콘만 있는 버튼에는 이름을 붙입니다.
인쇄 ⌘P 공유

더보기 메뉴

자주 쓰지 않는 동작을 접어 둡니다. 열려 있는 동안 버튼의 판은 맞춰진 채로 남습니다.

  • 화살표 키로 이동, Esc로 닫기.
  • 위험한 동작은 굵은 먹 선 아래 맨 끝에.

판이 왜 어긋나나요?
리소그래프는 색마다 판을 따로 돌립니다. 종이가 들어가는 위치가 매번 조금씩 달라서, 두 번째 색이 1mm 안팎 밀립니다. Riso는 이 어긋남을 일부러 남겨 둡니다.
세 번째 색은 어떻게 만드나요?
만들지 않습니다. 블루와 핑크를 겹치면 보라가 됩니다. 필요한 색은 겹침과 망점 농도로 냅니다.
어두운 화면도 있나요?
아직 없습니다. 종이 위의 잉크라는 전제라서, 어두운 버전은 '검은 종이에 형광 잉크'로 따로 설계할 예정입니다.

07

띄우기

화면 위에 무언가를 올릴 때도 그림자 대신 판을 씁니다. 블루와 핑크 판이 종이 뒤로 밀려 찍혀서 '위에 놓였다'는 것을 보여 줍니다.

확인 창

되돌릴 수 없는 일 앞에서만. 뒤 화면은 망점으로 눌러 둡니다.

  • 버튼은 결과를 말합니다: "삭제" 대신 "원고 3개 삭제".
  • Esc나 ×로 닫힙니다.

옆 판

현재 화면을 떠나지 않고 자세히 보거나 고칠 때. 왼쪽 가장자리는 절취선입니다.
