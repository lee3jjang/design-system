CH-01FOUNDATIONCAUTION · READ FIRST

기초BASE

조종석 안은 어둡습니다. 바탕은 짙은 남색과 흑연 금속, 정보는 녹색 인광 한 가지 선으로 그립니다. 아군은 차가운 하늘색, 주의는 호박색, 위협은 신호 빨강. 색이 곧 상태입니다.

PNL 1-A · 색 토큰12 VAR
PNL 1-B · 선 언어HUD LINE

하나의 HUD 선 LINE

모든 화면 요소는 1.5–2px 녹색 선으로. 모서리 브래킷, 눈금 사다리, 다이아몬드 표적. 굵기와 각도를 섞지 않습니다.

  • 브래킷: 화면, 카드, 포커스
  • 눈금: 판 가장자리, 테이프, 슬라이더
  • 위험 줄무늬: 물리적으로 위험한 것에만
PNL 1-C · 글자TYPE

글자 TYPE

한글 제목은 본고딕 Black으로 굵고 단단하게. 라틴 라벨은 사이라 컨덴스드, 숫자는 옥사늄으로 계기처럼.

  1. 색이 곧 상태녹색은 내 것과 정상, 하늘색은 아군, 호박색은 주의, 빨강은 위협. 장식으로 색을 쓰지 않습니다.
  2. 선은 하나HUD는 1.5px 녹색 선 한 가지. 브래킷과 눈금으로 묶고, 그림자나 그라데이션으로 꾸미지 않습니다.
  3. 딸깍, 철컥움직임은 기계처럼 짧고 정확하게. 스냅하고 미끄러지고 잠깁니다. 떠다니거나 출렁이지 않습니다.
  4. 장갑 낀 손으로누르는 곳 44px 이상, 본문 16.5px, 대비 4.5:1 이상. 움직임 줄이기 설정이면 흔들림과 회전을 멈춥니다.
